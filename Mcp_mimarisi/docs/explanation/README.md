# explanation/

Tasarım ve arka plan. Soru: **"Neden böyle karar verildi?"**

Örnek: "Şu mimari karar neden alındı, hangi alternatifler elendi", "şu
güvenlik akışının arkasındaki tehdit modeli ne". Adım tarif etmez, karar
gerekçesini kayıt altına alır — böylece 6 ay sonra biri "neden bunu böyle
yapmışız?" diye sormaz.
