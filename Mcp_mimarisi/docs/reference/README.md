# reference/

Kesin teknik başvuru. Soru: **"X'in tam/kesin şekli ne?"**

Örnek: "API sözleşmesi (endpoint/request/response şeması)", "env
değişkenleri listesi", "tool/komut listesi". Anlatım değil, **doğru ve
güncel** olması gereken kesin bilgi. Kodla çelişirse kod kazanır — belge
hemen düzeltilir.
